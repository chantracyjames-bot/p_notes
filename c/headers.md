
# Headers
- Definition:
	- Declared at the start of the program, required to use the features of each respective header like _printf()_, _scanf()_, _malloc()_, etc.
- Syntax:
```
	#include
```
- Libraries:
	- _errno.h_
		- Definition
			- Enables the use of errno, used for error handling.	
		- Syntax:
			```
			#include <errno.h>
			```
	- _math.h_
		- Definition		
			- Includes the math functions and libraries, enabling the use of math functions.
		- Syntax:
			```
			#include <math.h>
			```
	- _stdbool.h_
		- Definition:
			- Includes the boolean libraries, enables the use of the bool data type.
		- Syntax:
			```
			#include <stdbool.h>
			```
	- _stdlib.h_
		- Definition:
			- Includes most of the low-level libraries, like for dynamic memory management.
		- Syntax:
			```
			#include <stdlib.h>
			```
	- _stdio.h_
		- Definition:
			- Includes the input and output libraries, like _printf()_ for output and _scanf()_ for input.
		- Syntax:
			```
			#include <stdio.h>
			```
	- _string.h_
		- Definition:
			- Includes the string libraries and functions, enabling the use of string functions.
		- Syntax:
			```
			#include <string.h>
			```
