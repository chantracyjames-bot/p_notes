
# Change Directory (cd)
- Definition:
	- Used to change the current working directory.
- Syntax:
```
cd <directory>
```
- Example:
```
cd my_folder/
```
- Common options
	- ..
		- Definition:
			- Two dots, used to move back a single directory level, i.e. to the parent directory.
		- Syntax:
			```
			cd ..
			#> or
			cd ../
			```
	- ~
		- Definition:
			- A tilde, moves to the home directory, usually /home/user.
		- Syntax:
			```
			cd ~
			#> or
			cd ~/
			```
	- -
		- Definition:
			- A hyphen, moves to the last directory visited, i.e. the directory before the _cd_ command.
		- Syntax:
			
			```
			cd -
			```
	- /
		- Definition:
			- A frontslash, moves to the root directory.
		- Syntax:
			```
			cd /
			```
